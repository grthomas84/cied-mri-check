# CIED MRI Check

Web tool that checks whether a pacemaker / CIED system is MRI-conditional and how it should be programmed for MRI. Based on the CCS/CanSCMR/CHRS 2021 joint statement on MRI safety (Paterson DI et al., *Can J Cardiol* 2021;37:835–847).

Paste device information (manufacturer, model, serial number, leads), review the components, answer the patient and scan questions, then press **Is my device compatible?**

**Clinical decision support only.** Always confirm the full system with the manufacturer's MRI lookup and the heart rhythm device team before scanning.

## Files
- `index.html`: the whole app (no build step)
- `logo.png`: clinic logo
